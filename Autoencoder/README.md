### Simple autoencoder using MNIST dataset

In this project, I aimed to create and experiment with a simple autoencoder.
I used 60,000 images from the MNIST dataset for training and visualized the progress throughout the training process.
This project was also intended to prepare me for my bachelor's project, where I plan to implement an autoencoder to feed a diffusion model.
Additionally, for future reference, I made an effort to write clean and well-structured code.
